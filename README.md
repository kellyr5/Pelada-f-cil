## 🎯 Sobre o Projeto

**Pelada Fácil** é uma plataforma multiesportiva revolucionária que resolve o problema crônico de organização e engajamento no esporte amador brasileiro. Conectamos atletas, organizamos partidas e gerenciamos campeonatos de forma profissional e intuitiva.

### 🚀 Características Principais

- **🎯 Mercado de Jogadores**: Encontre jogadores próximos em segundos com sistema de matching inteligente
- **🎮 Gamificação Completa**: Estatísticas, conquistas, badges e ranking nacional
- **⚽ Multiesportivo**: Futebol, Futsal, Vôlei, Basquete, Tênis e Padel
- **🏆 Gestão de Campeonatos**: Organize ligas e torneios completos com tabelas automáticas
- **📱 Multiplataforma**: Web, iOS e Android

## 📊 Mercado

- **65 milhões** de atletas amadores no Brasil
- **15.3 milhões** praticam futebol regularmente
- **39.3%** dos praticantes de esporte jogam futebol
- Mercado em crescimento com alta demanda por organização

## 🚀 Como Executar

### Opção 1: Abrir diretamente
1. Clone o repositório
```bash
git clone https://github.com/seu-usuario/pelada-facil.git
```

2. Abra o arquivo `index.html` em seu navegador

### Opção 2: Servidor local
1. Usando Python:
```bash
python -m http.server 8000
```

2. Usando Node.js (http-server):
```bash
npx http-server
```

3. Acesse `http://localhost:8000` no navegador
