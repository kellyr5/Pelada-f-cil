## ✅ MÉTODO 1: ABRIR DIRETO NO NAVEGADOR (MAIS FÁCIL)

### Passo 1: Encontre o arquivo
1. Abra o **Explorador de Arquivos** no seu computador
2. Navegue até: `/home/user/Pelada-f-cil`
   - Ou cole este caminho na barra de endereço do explorador

### Passo 2: Abra o site
1. Procure o arquivo chamado **index.html**
2. **Clique duas vezes** nele
3. PRONTO! O site abrirá no seu navegador padrão

---

## 🌐 MÉTODO 2: SERVIDOR LOCAL (MELHOR OPÇÃO)

Este método é melhor porque carrega todos os recursos corretamente.

### PARA WINDOWS:

#### Opção A - Usando Python:
```bash
# 1. Abra o Prompt de Comando (CMD) ou PowerShell
# 2. Navegue até a pasta:
cd C:\Users\SEU_USUARIO\Pelada-f-cil

# 3. Execute:
python -m http.server 8000

# 4. Abra o navegador e digite:
http://localhost:8000
```

#### Opção B - Usando Node.js (se tiver instalado):
```bash
# 1. Abra o terminal
# 2. Navegue até a pasta:
cd C:\Users\SEU_USUARIO\Pelada-f-cil

# 3. Execute:
npx http-server -p 8000

# 4. Abra o navegador e digite:
http://localhost:8000
```

---

### PARA LINUX/MAC:

## 🔧 MÉTODO 3: USANDO VS CODE (SE VOCÊ USA)

### Passo 1: Abrir no VS Code
1. Abra o **Visual Studio Code**
2. Vá em: **File → Open Folder**
3. Selecione a pasta: `Pelada-f-cil`

### Passo 2: Instalar extensão Live Server
1. No VS Code, clique no ícone de **Extensões** (quadrado no lado esquerdo)
2. Pesquise: **Live Server**
3. Clique em **Install** na extensão do Ritwick Dey

### Passo 3: Iniciar servidor
1. Abra o arquivo **index.html** no VS Code
2. Clique com botão direito no código
3. Selecione: **Open with Live Server**
4. PRONTO! O site abrirá automaticamente

## ❓ PROBLEMAS COMUNS

### "Não encontrei a pasta"
- A pasta está em: `/home/user/Pelada-f-cil`
- No Windows pode estar em: `C:\Users\SEU_NOME\Pelada-f-cil`

### "Python não é reconhecido"
Você precisa instalar o Python:
1. Acesse: https://www.python.org/downloads/
2. Baixe e instale
3. Durante instalação, marque **"Add Python to PATH"**

### "A página não carrega"
1. Verifique se o servidor está rodando
2. Tente outro navegador
3. Limpe o cache (Ctrl+F5)

### "CSS/JS não funcionam"
Use o MÉTODO 2 (servidor local) ao invés de abrir direto
